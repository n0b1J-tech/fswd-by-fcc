Massive PHP Vulnerability Exposes 70% of the Web

A catastrophic global cybersecurity crisis has erupted following the leak of PHP2Shell, two highly critical, unauthenticated remote code execution (RCE) vulnerabilities (CVE-2026-109618 and CVE-2026-109619). Discovered using AI tools, the flaws affect virtually all PHP installations serving web requests going back to PHP 5 (released in 2004)—putting roughly 70% of all websites at risk of total server takeover via a single crafted request.
